🚀 ESA Auto ML
ESA Auto ML è una piattaforma AutoML sviluppata per automatizzare il processo di Machine Learning, dalla preparazione dei dati fino alla validazione finale del modello.

Il progetto nasce con l'obiettivo di semplificare le attività di Data Science e consentire anche a utenti non esperti di sperimentare e valutare modelli di Intelligenza Artificiale attraverso un flusso di lavoro guidato e automatizzato.

Principali funzionalità

✅ Importazione dataset CSV

✅ Preprocessing automatico dei dati

✅ Addestramento dei modelli Machine Learning

✅ Cross Validation automatica

✅ Analisi delle performance

✅ Rilevamento dell'overfitting

✅ Test del modello su dati mai utilizzati durante il training

✅ Esportazione del modello addestrato

✅ Interfaccia semplice e intuitiva

Tecnologie utilizzate
Python
Scikit-Learn
Pandas
NumPy
Joblib
Matplotlib
Caso di studio
ESA Auto ML è stato testato su dataset relativi a motori elettrici per verificare la capacità di generalizzazione dei modelli AI su dati mai visti in fase di addestramento.

Le analisi comprendono:

Training automatico
Cross Validation
Monitoraggio del gap di generalizzazione
Valutazione finale su dataset indipendenti
